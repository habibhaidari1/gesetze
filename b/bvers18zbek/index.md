# Bekanntmachung über die Zahl der von den Volksvertretungen der Länder zu wählenden Mitglieder der 18. Bundesversammlung (BVers18ZBek)

Ausfertigungsdatum
:   2026-09-16

Fundstelle
:   BGBl. I: 2026, Nr. 267


## (XXXX)

Auf Grund des § 2 Absatz 1 des Gesetzes über die Wahl des
Bundespräsidenten durch die Bundesversammlung in der im
Bundesgesetzblatt Teil III, Gliederungsnummer 1100-1, veröffentlichten
bereinigten Fassung, das zuletzt durch Artikel 1 des Gesetzes vom
12\. Juli 2007 (BGBl. I S. 1326) geändert worden ist, stellt die
Bundesregierung fest:

Zur 18. Bundesversammlung wählt die Volksvertretung des Landes

| Bayern | 99 Mitglieder |
| Berlin | 26 Mitglieder |

| Bremen | 5 Mitglieder |

| Hessen | 45 Mitglieder |
| Mecklenburg-Vorpommern | 13 Mitglieder |
| Niedersachsen | 63 Mitglieder |
| Nordrhein-Westfalen | 134 Mitglieder |
| Rheinland-Pfalz | 31 Mitglieder |
| Saarland | 8 Mitglieder |

| Sachsen-Anhalt | 17 Mitglieder |
| Schleswig-Holstein | 23 Mitglieder |
